Password Generator

Create strong, random passwords for email, banking apps and staff logins. Choose the length and character types, and avoid look-alike characters if you need to read the password out.

How to use the Password Generator

  1. Choose the length (16 or more is best).
  2. Pick character types.
  3. Copy a password.

Formula

Strength (bits) = Length × log2(number of possible characters)

Example

A 16-character password using all four types is about 100 bits — practically impossible to guess.
